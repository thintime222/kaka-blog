## 日志更新

### 2026-04-25

新功能

1. 全新博客上线，基于 Vite + React 18 + MDX 技术栈，提供更快的加载速度和更流畅的浏览体验
2. 支持基于 MDX 文件约定的自动路由生成，新增文章无需手动配置路由
3. 菜单根据 MDX 文章内容动态生成，分类、目录始终与最新内容同步
4. 引入路由懒加载，按需加载页面资源，首屏打开更快
5. 新增 [关于](/about)、[简历](/md/resume)、[更新日志](/log) 页面
6. 内置前端、后端、技术栈、组件库、工具等多个分类的技术文章合集
7. 支持 GitHub 风格的 Markdown 渲染，代码与文档阅读体验更接近原生 GitHub

更新

1. 接入 Vercel 自动部署，每次发布后即时生效，无需等待
2. 默认进入分类时自动选中第一篇文章，少一次点击直达内容
